# Thesis experimental source code

| Directory | Study | Supported OS |
| --- | --- | --- |
| [LLM](LLM/README.md) | Local Ollama classification | Windows |
| [LSTM_SPEDIA](LSTM_SPEDIA/README.md) | Preliminary SPEDIA/LSTM study | Linux |
